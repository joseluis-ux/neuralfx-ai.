# NeuralFX.ai

Neural Trading Bot Builder — AI-powered node-based strategy creator.

## Demo
https://neuralfx-ai.vercel.app

## Instalación
1. Clona el repo:
   git clone https://github.com/joseluis-ux/neuralfx-ai..git
2. Entra al directorio:
   cd "neuralfx-ai."
3. Sirve localmente:
   python3 -m http.server 8000
   Abrir http://localhost:8000
